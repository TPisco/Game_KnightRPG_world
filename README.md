# 🛡️ KnightRPG: Fractured Worlds

> *A lone knight. Endless worlds. Power beyond imagination.*

---

## 🌌 Overview

**KnightRPG: Fractured Worlds** is a 3D action RPG built with the **Godot Engine**, where you step into the armor of a lost knight thrown into an infinite, ever-changing universe.

Your mission?
Survive. Grow stronger. Defeat ancient bosses. And uncover a way back to your original world.

Every run is different. Every world is unpredictable. Every choice matters.

---

## ⚔️ Core Features

### 🌍 Infinite World Generation

* Procedurally generated 3D environments
* Unique terrain, encounters, and loot every time you play
* Endless exploration with escalating danger

### 🧙 Powers & Skills System

* Discover powerful abilities hidden across worlds
* Customize your build: strength, magic, defense, or hybrid
* Adapt to survive increasingly brutal enemies

### 👹 Epic Boss Battles

* Face off against massive, unique bosses
* Each boss introduces new mechanics and challenges
* Learn, adapt, and conquer

### 🎒 Enhanced Inventory System

* Dynamic inventory management
* Collect weapons, artifacts, and upgrades
* Optimize your loadout for survival

### 🛡️ Player Progression

* Grow stronger with every encounter
* Unlock new skills and passive abilities
* Shape your knight into a legend

---

## 🧩 Story

You are a knight torn from your world by a mysterious force.
Thrown into a fractured multiverse, you must fight your way through hostile lands filled with forgotten powers and ancient beings.

Somewhere beyond the chaos lies a path home...
But only the strongest will ever find it.

## 🚀 Getting Started

### Requirements

* Godot Engine (recommended version: 4.x)

### Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/TPisco/Game_KnightRPG_world.git
   ```
2. Open **Godot**
3. Import the project folder
4. Press ▶️ Play
